# 编辑，提取，合并

字典可以设置多个键对值，也可以单独提取、合并

```c
dict dictval = set("a",3.0,"b","text");

float cval = getcomp(dictval,"a",-1.0);
f@cval = cval;
```

getcomp获取*dictval*里的a键，如果a值存在，即获得a的值；如果a值不存在即新添一个a并将值设为-1.0



```c
dict dictval1 = set("a",1,"b",2);
dict dictval2 = set("c",3,"d",4);

insert(dictval1,dictval2);

d@dictval = dictval1;
```

insert可以将*dictval2*的键对添加到*dictval1*中



## Json格式

json_dumps可以将字典中的键对值转为string依次写入；



```c
string json = s@json;

dict dictval = json_loads(json , 2);

d@dictval = dictval;
```

json_loads可以将json中的字符串显示的表达出来，2为显示表达，1为隐式表达，0为自动判断。
